# Warung Digital 📱

Aplikasi **Warung Digital** merupakan aplikasi mobile berbasis Android yang dibuat untuk membantu pengelolaan warung secara digital. Aplikasi ini memungkinkan pengguna untuk melihat produk, menambahkan produk, melakukan transaksi sederhana, serta melihat riwayat aktivitas penjualan.

Project ini dibuat menggunakan **React Native dengan Expo**.

---

## 📌 Fitur Aplikasi

### 1. Dashboard
- Menampilkan halaman utama aplikasi
- Informasi ringkasan produk
- Navigasi menuju fitur utama

### 2. Product Management
- Melihat daftar produk
- Menambahkan produk baru
- Menampilkan detail produk
- Mengelola data produk

### 3. History Transaksi
- Melihat riwayat transaksi
- Menampilkan daftar pembelian yang telah dilakukan

### 4. Add Product
- Menambahkan data produk baru
- Input:
  - Nama produk
  - Harga produk
  - Kategori
  - Stok
  - Gambar produk

### 5. Search Product
- Mencari produk secara realtime berdasarkan nama produk
